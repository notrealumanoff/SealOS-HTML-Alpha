For reference, I did not make this web-based operating system myself, I used artificial intelligence to write the code to see what I could eventually learn to do and add to this in the future.
This is a project I have with one of my friends for people who don't want to use any of the popular operating systems, including Windows, macOS, more popular Linux distros (e.g. Ubuntu, Arch and Fedora).
It will also hopefully be designed to run apps for Linux, Windows, macOS.
Thank you for viewing this repository with a project I hope to finish.
To view the current versions of the operating systems, download a copy of either the operating system with the assistant or without the assistant, and then open the file after downloading it, and you will be able to view it in your web browser.
